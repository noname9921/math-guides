🔷 Exponents
Laws of Exponents \begin{align*} a^m \cdot a^n = a^{m+n}\\ \frac{a^m}{a^n} = a^{m-n}\\ (ab)^n = a^n \cdot b^n\\ (a^m)^n = a^{mn}\\ a^0 = 1\\ a^{-n} = \frac{1}{a^n}\\ a^{\frac{m}{n}} = \sqrt[n]{a^m}\\ \end{align*} Exponential Growth and Decay \begin{align*} y = a(1 + r)^t\\ y = a(1 - r)^t\\ \end{align*} Continous Growth and Decay \begin{align*} y = ae^{kt}\\ \end{align*} Solving Exponential Equations \begin{align*} a^x = b \Rightarrow x = \frac{\log(b)}{\log(a)}\\ e^x = a \Rightarrow x = \ln(a)\\ \end{align*}
🔷 Roots
Basic Roots Properties \begin{align*} \sqrt{a} \cdot \sqrt{b} = \sqrt{ab}\\ \frac{1}{\sqrt{a}} = \frac{\sqrt{a}}{a}\\ \sqrt[n]{a^m} = a^{\frac{m}{n}}\\ \sqrt{a^2} = |a|\\ \end{align*} Imaginary Unit Rules \begin{align*} \sqrt{-a} = i \cdot \sqrt{a}\\ i = \sqrt{-1}\\ i^2 = -1\\ i^3 = -i\\ i^4 = 1\\ \end{align*} Modulus of Complex Numbers \begin{align*} z = a + bi \Rightarrow |z| = \sqrt{a^2 + b^2}\\ \end{align*}
🔷 Trigonometry
Trigonometry Ratios \begin{align*} \sin(\theta) = \frac{\text{opposite}}{\text{hypotenuse}}\\ \cos(\theta) = \frac{\text{adjacent}}{\text{hypotenuse}}\\ \tan(\theta) = \frac{\text{opposite}}{\text{adjacent}}\\ \csc(\theta) = \frac{1}{\sin(\theta)}\\ \sec(\theta) = \frac{1}{\cos(\theta)}\\ \cot(\theta) = \frac{1}{\tan(\theta)}\\ \end{align*} Pythagorean Identites \begin{align*} \sin^2(x) + \cos^2(x) = 1\\ 1 + \tan^2(x) = \sec^2(x)\\ 1 + \cot^2(x) = \csc^2(x)\\ \end{align*} Double Angle Identities \begin{align*} \sin(2x) = 2\sin(x)\cos(x)\\ \cos(2x) = \cos^2(x) - \sin^2(x)\\ \tan(2x) = \frac{2\tan(x)}{1 - \tan^2(x)}\\ \end{align*} Power Reduction \begin{align*} \sin^2(x) = \frac{1 - \cos(2x)}{2}\\ \cos^2(x) = \frac{1 + \cos(2x)}{2}\\ \end{align*}
🔷 Logarithms
Definition and Base Change \begin{align*} \log_b(a) = x \Leftrightarrow b^x = a\\ \log_b(a) = \frac{\log_c(a)}{\log_c(b)}\\ \ln(x) = \log_e(x)\\ \end{align*} Logarithmic Properties \begin{align*} \log_b(xy) = \log_b(x) + \log_b(y)\\ \log_b\left(\frac{x}{y}\right) = \log_b(x) - \log_b(y)\\ \log_b(x^n) = n\log_b(x)\\ \log(ab^c) = \log(a) + c\log(b)\\ \end{align*} Exponential-Log Inversion \begin{align*} e^{\ln(x)} = x\\ \ln(e^x) = x\\ \log_{a^n}(x) = \frac{1}{n} \log_a(x)\\ \end{align*}
🔷 Calculus
Basic Derivatives \begin{align*} \frac{d}{dx} x^n = nx^{n-1}\\ \frac{d}{dx} \sin(x) = \cos(x)\\ \frac{d}{dx} \cos(x) = -\sin(x)\\ \frac{d}{dx} \tan(x) = \sec^2(x)\\ \frac{d}{dx} \ln(x) = \frac{1}{x}\\ \frac{d}{dx} e^x = e^x\\ \frac{d}{dx} a^x = a^x \ln(a)\\ \end{align*} Rules of Differentiation \begin{align*} \frac{d}{dx}(uv) = u'v + uv'\\ \frac{d}{dx} \left(\frac{u}{v}\right) = \frac{u'v - uv'}{v^2}\\ \frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)\\ \end{align*} Basic Integrals \begin{align*} \int x^n \, dx = \frac{x^{n+1}}{n+1} + C\\ \int \frac{1}{x} \, dx = \ln|x| + C\\ \int e^x \, dx = e^x + C\\ \int \sin(x) \, dx = -\cos(x) + C\\ \int \cos(x) \, dx = \sin(x) + C\\ \end{align*} Definite Integrals \begin{align*} \int_a^b f(x) \, dx = F(b) - F(a)\\ \end{align*} Integration by Parts \begin{align*} \int u \cdot v' \, dx = uv - \int u'v \, dx\\ \end{align*}
🔷 Geometry
2D Geometry - Area and Perimeter \begin{align*} A_{\text{square}} = a^2\\ A_{\text{rectangle}} = l \cdot w\\ A_{\text{triangle}} = \frac{1}{2} b h\\ A_{\text{circle}} = \pi r^2\\ A_{\text{trapezoid}} = \frac{1}{2}(a + b)h\\ C_{\text{circle}} = 2\pi r\\ P_{\text{rectangle}} = 2(l + w)\\ P_{\text{square}} = 4a\\ \end{align*} 2D Geometry - Angles \begin{align*} \text{Sum of angles in triangle} = 180^\circ\\ \text{Exterior angle of triangle} = \text{sum of opposite interior angles}\\ \text{Parallel lines: alternate interior angles are equal}\\ \text{Complementary: sum to } 90^\circ,\quad \text{Supplementary: } 180^\circ\\ \text{Angles in semicircle} = 90^\circ\\ \text{Cyclic quadrilateral: opposite angles sum to } 180^\circ\\ \end{align*} 2D Geometry - Coordinate
