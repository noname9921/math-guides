MATH GUIDE

🔷 Exponents
Laws of Exponents \begin{align*} a^m \cdot a^n = a^{m+n}\\ \frac{a^m}{a^n} = a^{m-n}\\ (ab)^n = a^n \cdot b^n\\ (a^m)^n = a^{mn}\\ a^0 = 1\\ a^{-n} = \frac{1}{a^n}\\ a^{\frac{m}{n}} = \sqrt[n]{a^m}\\ \end{align*} Exponential Growth and Decay \begin{align*} y = a(1 + r)^t\\ y = a(1 - r)^t\\ \end{align*} Continous Growth and Decay \begin{align*} y = ae^{kt}\\ \end{align*} Solving Exponential Equations \begin{align*} a^x = b \Rightarrow x = \frac{\log(b)}{\log(a)}\\ e^x = a \Rightarrow x = \ln(a)\\ \end{align*}
🔷 Roots
Basic Roots Properties \begin{align*} \sqrt{a} \cdot \sqrt{b} = \sqrt{ab}\\ \frac{1}{\sqrt{a}} = \frac{\sqrt{a}}{a}\\ \sqrt[n]{a^m} = a^{\frac{m}{n}}\\ \sqrt{a^2} = |a|\\ \end{align*} Imaginary Unit Rules \begin{align*} \sqrt{-a} = i \cdot \sqrt{a}\\ i = \sqrt{-1}\\ i^2 = -1\\ i^3 = -i\\ i^4 = 1\\ \end{align*} Modulus of Complex Numbers \begin{align*} z = a + bi \Rightarrow |z| = \sqrt{a^2 + b^2}\\ \end{align*}
🔷 Trigonometry
Trigonometry Ratios \begin{align*} \sin(\theta) = \frac{\text{opposite}}{\text{hypotenuse}}\\ \cos(\theta) = \frac{\text{adjacent}}{\text{hypotenuse}}\\ \tan(\theta) = \frac{\text{opposite}}{\text{adjacent}}\\ \csc(\theta) = \frac{1}{\sin(\theta)}\\ \sec(\theta) = \frac{1}{\cos(\theta)}\\ \cot(\theta) = \frac{1}{\tan(\theta)}\\ \end{align*} Pythagorean Identites \begin{align*} \sin^2(x) + \cos^2(x) = 1\\ 1 + \tan^2(x) = \sec^2(x)\\ 1 + \cot^2(x) = \csc^2(x)\\ \end{align*} Double Angle Identities \begin{align*} \sin(2x) = 2\sin(x)\cos(x)\\ \cos(2x) = \cos^2(x) - \sin^2(x)\\ \tan(2x) = \frac{2\tan(x)}{1 - \tan^2(x)}\\ \end{align*} Power Reduction \begin{align*} \sin^2(x) = \frac{1 - \cos(2x)}{2}\\ \cos^2(x) = \frac{1 + \cos(2x)}{2}\\ \end{align*}
🔷 Logarithms
Definition and Base Change \begin{align*} \log_b(a) = x \Leftrightarrow b^x = a\\ \log_b(a) = \frac{\log_c(a)}{\log_c(b)}\\ \ln(x) = \log_e(x)\\ \end{align*} Logarithmic Properties \begin{align*} \log_b(xy) = \log_b(x) + \log_b(y)\\ \log_b\left(\frac{x}{y}\right) = \log_b(x) - \log_b(y)\\ \log_b(x^n) = n\log_b(x)\\ \log(ab^c) = \log(a) + c\log(b)\\ \end{align*} Exponential-Log Inversion \begin{align*} e^{\ln(x)} = x\\ \ln(e^x) = x\\ \log_{a^n}(x) = \frac{1}{n} \log_a(x)\\ \end{align*}
🔷 Calculus
Basic Derivatives \begin{align*} \frac{d}{dx} x^n = nx^{n-1}\\ \frac{d}{dx} \sin(x) = \cos(x)\\ \frac{d}{dx} \cos(x) = -\sin(x)\\ \frac{d}{dx} \tan(x) = \sec^2(x)\\ \frac{d}{dx} \ln(x) = \frac{1}{x}\\ \frac{d}{dx} e^x = e^x\\ \frac{d}{dx} a^x = a^x \ln(a)\\ \end{align*} Rules of Differentiation \begin{align*} \frac{d}{dx}(uv) = u'v + uv'\\ \frac{d}{dx} \left(\frac{u}{v}\right) = \frac{u'v - uv'}{v^2}\\ \frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)\\ \end{align*} Basic Integrals \begin{align*} \int x^n \, dx = \frac{x^{n+1}}{n+1} + C\\ \int \frac{1}{x} \, dx = \ln|x| + C\\ \int e^x \, dx = e^x + C\\ \int \sin(x) \, dx = -\cos(x) + C\\ \int \cos(x) \, dx = \sin(x) + C\\ \end{align*} Definite Integrals \begin{align*} \int_a^b f(x) \, dx = F(b) - F(a)\\ \end{align*} Integration by Parts \begin{align*} \int u \cdot v' \, dx = uv - \int u'v \, dx\\ \end{align*}
🔷 Geometry
2D Geometry - Area and Perimeter \begin{align*} A_{\text{square}} = a^2\\ A_{\text{rectangle}} = l \cdot w\\ A_{\text{triangle}} = \frac{1}{2} b h\\ A_{\text{circle}} = \pi r^2\\ A_{\text{trapezoid}} = \frac{1}{2}(a + b)h\\ C_{\text{circle}} = 2\pi r\\ P_{\text{rectangle}} = 2(l + w)\\ P_{\text{square}} = 4a\\ \end{align*} 2D Geometry - Angles \begin{align*} \text{Sum of angles in triangle} = 180^\circ\\ \text{Exterior angle of triangle} = \text{sum of opposite interior angles}\\ \text{Parallel lines: alternate interior angles are equal}\\ \text{Complementary: sum to } 90^\circ,\quad \text{Supplementary: } 180^\circ\\ \text{Angles in semicircle} = 90^\circ\\ \text{Cyclic quadrilateral: opposite angles sum to } 180^\circ\\ \end{align*} 2D Geometry - Coordinate \begin{align*} \text{Distance: } d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\\ \text{Midpoint: } M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)\\ \text{Slope: } m = \frac{y_2 - y_1}{x_2 - x_1}\\ \text{Line Equation: } y - y_1 = m(x - x_1)\\ \text{Circle: } (x - a)^2 + (y - b)^2 = r^2\\ \end{align*} 3D Geometry - Volume and Surface Area \begin{align*} V_{\text{cube}} = a^3,\quad SA_{\text{cube}} = 6a^2\\ V_{\text{rect. prism}} = lwh\\ V_{\text{cylinder}} = \pi r^2 h,\quad SA = 2\pi r(h + r)\\ V_{\text{cone}} = \frac{1}{3} \pi r^2 h\\ V_{\text{sphere}} = \frac{4}{3} \pi r^3,\quad SA = 4\pi r^2\\ V_{\text{pyramid}} = \frac{1}{3} \cdot \text{base area} \cdot h\\ \text{Diagonal of cube} = a\sqrt{3}\\ \end{align*} 3D Geometry - Coordinate \begin{align*} \text{3D Point: } (x, y, z)\\ \text{Distance in 3D: } d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}\\ \text{Midpoint in 3D: } M = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}, \frac{z_1 + z_2}{2} \right)\\ \text{Line segment or vector: } \vec{v} = \langle x_2 - x_1, y_2 - y_1, z_2 - z_1 \rangle\\ \end{align*} Vectro Geometry (Intro) \begin{align*} \vec{u} \cdot \vec{v} = u_1v_1 + u_2v_2 + u_3v_3\\ |\vec{v}| = \sqrt{x^2 + y^2 + z^2}\\ \text{Angle between vectors: } \cos\theta = \frac{\vec{u} \cdot \vec{v}}{|\vec{u}||\vec{v}|}\\ \text{Cross product: } \vec{u} \times \vec{v} = \text{area of parallelogram formed}\\ \end{align*} Important Theorems and Concepts \begin{align*} \text{Pythagorean Theorem: } a^2 + b^2 = c^2\\ \text{Similar triangles: corresponding angles equal, sides in ratio}\\ \text{Congruent triangles: SSS, SAS, ASA, RHS rules}\\ \text{Heron’s Formula: } A = \sqrt{s(s-a)(s-b)(s-c)} \quad \text{where } s = \frac{a+b+c}{2}\\ \text{Law of Sines: } \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}\\ \text{Law of Cosines: } c^2 = a^2 + b^2 - 2ab\cos C\\ \end{align*} Transformation in 2D Geometry \begin{align*} \text{Translation: } (x, y) \to (x + a, y + b)\\ \text{Reflection over x-axis: } (x, y) \to (x, -y)\\ \text{Reflection over y-axis: } (x, y) \to (-x, y)\\ \text{Rotation about origin (90° CCW): } (x, y) \to (-y, x)\\ \text{Dilation from origin (scale } k): (x, y) \to (kx, ky)\\ \text{Preserved: shape, angle, orientation (except in reflections)}\\ \end{align*} Conic Sections \begin{align*} \text{Circle: } (x - h)^2 + (y - k)^2 = r^2\\ \text{Ellipse: } \frac{(x - h)^2}{a^2} + \frac{(y - k)^2}{b^2} = 1\\ \text{Parabola (vertical): } y = ax^2 + bx + c\\ \text{Parabola (vertex form): } y - k = a(x - h)^2\\ \text{Hyperbola: } \frac{(x - h)^2}{a^2} - \frac{(y - k)^2}{b^2} = 1\\ \text{Foci, directrix, and eccentricity define each conic}\\ \end{align*} Olympiad Proof Strategies \begin{align*} \text{Use auxiliary lines: draw extra lines or points for symmetry}\\ \text{Angle chasing: assign and track known angle values}\\ \text{Power of a point: } PA \cdot PB = PC \cdot PD\\ \text{Similar triangles and ratios: powerful for length proofs}\\ \text{Use cyclic quadrilaterals: opposite angles sum to } 180^\circ\\ \text{Midpoints and medians: triangle center tricks (e.g., centroid)}\\ \text{Coordinate geometry proof: assign coordinates to prove congruence}\\ \text{or parallelism}\\ \end{align*}
🔷 Sequences
Arithmetic Sequence \begin{align*} a_n = a_1 + (n - 1)d\\ n = \frac{a_n - a_1}{d} + 1\\ S_n = \frac{n}{2}(a_1 + a_n)\\ \end{align*} Geometric Sequence \begin{align*} a_n = a_1 r^{n - 1}\\ m - k = \frac{log(\frac{a_m}{a_k})}{log(r)}, \quad a_n, a_1, r \neq 0\\ S_n = \frac{a_1(1 - r^n)}{1 - r}, \quad r \neq 1\\ S_\infty = \frac{a_1}{1 - r}, \quad |r| < 1\\ \end{align*} Recursive Formulas \begin{align*} a_n = a_{n-1} + d\\ a_n = a_{n-1} \cdot r\\ \end{align*}
🔷 Equations
Linear Equation \begin{align*} ax + b = 0 \Rightarrow x = -\frac{b}{a}\\ \end{align*} Quadratic Equation \begin{align*} ax^2 + bx + c = 0 \Rightarrow x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\\ \end{align*} Absolute Value Equation \begin{align*} |x| = a \Rightarrow x = \pm a\\ \end{align*} System of Equation \begin{align*} \text{Use substitution, elimination, or matrix methods}\\ \end{align*}
🔷 Polynomials
Standard Form \begin{align*} P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_0\\ \end{align*} Factoring Identities \begin{align*} a^2 - b^2 = (a - b)(a + b)\\ a^3 + b^3 = (a + b)(a^2 - ab + b^2)\\ a^3 - b^3 = (a - b)(a^2 + ab + b^2)\\ \end{align*} Zero and Factor Theorem \begin{align*} P(c) = 0 \Rightarrow (x - c) \text{ is a factor of } P(x)\\ \end{align*}
